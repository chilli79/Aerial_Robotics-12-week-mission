# 🚀 12 Weeks: Mission Autonomous UAV Engineer

**A 12-week engineering challenge in Aerial Robotics, Autonomous Systems and Defence Aptitude.**

I'm building my foundations in mathematics, robotics, control systems and autonomous flight while strengthening my practical engineering skills.

This repository is my public accountability record. Every week must produce evidence of learning — code, calculations, simulations, experiments or technical documentation.

## 🎯 Mission objectives

- [ ] Build strong mathematical foundations for robotics.
- [ ] Understand UAV dynamics and modelling.
- [ ] Learn control systems and trajectory generation.
- [ ] Implement path planning algorithms.
- [ ] Explore computer vision and visual navigation.
- [ ] Understand state estimation and sensor fusion.
- [ ] Build and document an autonomous UAV simulation.
- [ ] Prepare consistently for AFCAT.

## 🗓️ Weekly execution rules

Every week, I will:

- [ ] Complete 8 hours of engineering study.
- [ ] Complete 5 hours of AFCAT preparation.
- [ ] Spend 2 hours on testing, revision and weekly review.
- [ ] Produce at least one tangible engineering output.
- [ ] Read and analyse one relevant technical paper or research section.
- [ ] Document mistakes and concepts I couldn't explain.
- [ ] Publish a weekly progress report.

**Total target: 15 hours/week · 180 hours/12 weeks**

## 🧪 Engineering evidence

I will not count watching lectures as project completion.

A task is complete only when I can show at least one of these:

- Working code
- A mathematical derivation
- A simulation
- A circuit or hardware prototype
- A test result
- A technical explanation
